Концепция «Рабочий стол»

Идея: ocbar вписывается в обычный рабочий день на одном Mac. Главный образ —
узнаваемые браузеры YouTube и рабочего портала, Finder с папками домашнего NAS.
Три цветных пути наложены поверх рабочего стола и заканчиваются отдельными
назначениями. Палитра: бумажный белый, приглушённый зелёный, лавандовый и охра;
мягкие маковские окна и широкие поля вместо сетки рекламных карточек.

artwork.svg — самостоятельный экспорт 1200 × 820, системный шрифт, демо-данные,
внутренние определения градиентов/маркеров/тени. Не зависит от HTML или картинки.
dns.svg — самостоятельная векторная схема: запрос имени пунктиром, трафик
после разрешения имени сплошной зелёной линией.

index.html + style.css + script.js работают без сборки, библиотек и remote fonts.
Страница использует настоящие menu-light-ru.png и profile-light-ru.png
из ../assets/. Картинки интерфейса увеличиваются в native dialog с Esc.
Навигация ведёт к секциям; установка и GitHub — к URL из brief.
Переключатели маршрутов дают подробности выбранного пути. Сравнение режимов
переключает путь внешнего адреса и пояснение; клавиши ←/→, Home/End работают.

Ограничения:
- Окна браузеров/Finder иллюстративные. SVG не копирует чужие скриншоты.
- Маршруты заданы сетями и адресами; нет обещания привязки процесса к VPN.
- Личный VPN на схеме управляется отдельным клиентом, не ocbar.
- В full tunnel локальный NAS не объявляется недоступным: это зависит
  от маршрутов/политик. Не оцениваем возможности всех Cisco-клиентов.
- На 390/320 главная схема сохраняет читаемые окна и прокручивается внутри
  своей области. Это намеренный компромисс: широкую композицию не ужимаем
  до нечитаемых подписей. DNS также прокручивается внутри своей фигуры.
- Анимации отсутствуют, smooth scroll отключается при reduced-motion.
- Не выполнялся browser QA по условиям задачи; родитель проверяет скриншоты.

Проверки: XML parsing обоих SVG, HTML ids/link targets/asset paths,
синтаксис JS, отсутствие удалённых ресурсов/новых зависимостей.
