04 / ИНСТРУМЕНТЫ ПОД РУКОЙ

Утилита с характером.
И доступом к деталям.

A

Ваш CSD wrapper

Собственный скрипт HostScan запускается от вашего пользователя до SSO. На совместимом шлюзе для него не нужен Cisco Secure Client. Решение о допуске принимает шлюз.

CsdWrapper = ~/vpn/csd-post.sh
B

SOCKS для отдельных программ

Через OpenConnect и ocproxy направляйте в VPN браузер, Git или команду. При SystemProxy = off не нужны root-помощник, системные маршруты и изменение системного DNS.

127.0.0.1:11080
C

Диагностика без квеста

Маршруты, DNS, скорость, трафик и журналы доступны в приложении. Логи хранятся локально. Для открытия диагностики не нужно разрешение администратора VPN.

ocbar doctor
ocbar logs -f

06 / ВАША СБОРКА

Время собрать
свой клиент.

Homebrew собирает ocbar из исходников на вашем Mac. Нужны macOS 13+, Command Line Tools и доступ к совместимому VPN-шлюзу.

Установка и первое подключение ↗
УСТАНОВКА ИЗ TAP
brew tap ValeraGin/ocbar
brew trust ValeraGin/ocbar
brew install ocbar

Сторонний tap: изучите исходники перед подтверждением доверия. Сборка локальная, без подписанного и нотарифицированного установщика.

07 / ПЕРЕД ПОДКЛЮЧЕНИЕМ

Без магии.
И лишних обещаний.

Это сервис VPN?

ocbar — клиент к шлюзу, к которому у вас уже есть доступ. Своих VPN-серверов и сервиса анонимизации у проекта нет.

На чём проверено?

Автор ежедневно использует macOS 26 на Apple Silicon, AnyConnect и Keycloak SSO. macOS 13–25 и Intel ожидаются, но пока не проверены. Совместимость зависит от шлюза и его политики.

Для туннеля нужны права root?

Да: туннель использует привилегированного помощника, установленного через sudo ocbar install. Само приложение работает от пользователя. CSD-скрипт и SOCKS при SystemProxy = off работают без root. Модель безопасности ↗

Что происходит с учётными данными?

Секреты берутся из Связки ключей macOS, KeePassXC или вашей команды. Профиль хранит ссылки на источники. В ocbar нет аналитики, отправки crash-report и автоматической проверки обновлений.
