Свой CSD wrapper

Скрипт HostScan работает от вашего пользователя до SSO. На совместимом шлюзе для него не нужен Cisco Secure Client. Допуск определяет шлюз.

SOCKS для нужных программ

OpenConnect и ocproxy направят через VPN браузер, Git или команду. При SystemProxy = off — без root, системных маршрутов и изменения системного DNS.

Логи и диагностика под рукой

Сети, DNS, трафик и журналы доступны в приложении. Логи локальные, телеметрии нет.

на своём Mac.

Homebrew собирает ocbar из исходников. Нужны macOS 13+, Command Line Tools и доступ к совместимому AnyConnect-шлюзу.

Установка и первое подключение ↗
Установка из tap
brew tap ValeraGin/ocbar
brew trust ValeraGin/ocbar
brew install ocbar

Сторонний tap: изучите исходники перед подтверждением доверия. Сборка локальная, без подписанного и нотарифицированного установщика.

На чём проверено?

Автор использует macOS 26 на Apple Silicon, AnyConnect и Keycloak SSO. macOS 13–25 и Intel пока не проверены. Совместимость зависит от шлюза и его политики.

Для туннеля нужны права root?

Туннель использует привилегированного помощника: sudo ocbar install. Приложение работает от пользователя. CSD и SOCKS с SystemProxy = off работают без root. Модель безопасности ↗

Это сервис VPN?

ocbar подключается к вашему шлюзу. Своих VPN-серверов и сервиса анонимизации у проекта нет. Открытый код под MIT: можно изучать и менять под себя.
