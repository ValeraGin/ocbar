ВЫБРАННЫЙ ВАРИАНТ: САЙТ B + ИКОНКА A

Минималистичная переработка Workbench:
почти белый тёплый фон, чёрная типографика, редкий оранжевый акцент,
больше воздуха. Пять содержательных секций: первый экран, маршруты,
обмен .ocbar, настройки / возможности, установка. Без декоративной
macOS рамки, штампов, крестиков, секционных номеров и набора карточек.

Открыть index.html или /concepts/workbench/ на сервере website/.
icon.svg и icon-mono.svg — точные копии выбранной иконки маршрутов A
из ../terminal/: один вход разветвляется на два пути. Лист icons.html
показывает оба варианта в 16/24/32/64/128/256 на светлом и тёмном фоне.
В листе размеров монохромный SVG встроен с currentColor для двух тем.
Для AppKit menu bar монохромную иконку нужно использовать как template.

Взаимодействия:
- два переключателя маршрутов, направление и счётчик меняются;
- три этапа передачи .ocbar, ссылка переводит на второй этап;
- выбор реального скриншота меню / профиля;
- увеличение скриншотов, закрытие кнопкой / Escape / фоном;
- шаги установки и копирование команд (fallback — выделение);
- FAQ раскрывается через details;
- tabs доступны стрелками, Home / End;
- реальные ссылки на GitHub, MIT и инструкцию установки.

Схема и передача профиля помечены как демо. Команды не исполняются.
Скриншоты ../../dist/assets/ не редактируются и содержат текущую иконку.
Без зависимостей, внешних шрифтов и сетевых ассетов.

Тексты сохраняют ограничения продукта: одна своя VPN-сессия;
соседство с другим VPN при непротиворечивых маршрутах / DNS;
CSD и SOCKS при SystemProxy=off без root, обычный туннель с помощником;
допуск определяет шлюз; нет своих VPN-серверов; секреты из хранилищ
не экспортируются, перед передачей проверяются логин, пути и команды.

Статические проверки: node --check script.js, HTML IDs / anchors /
ARIA / локальные ссылки, SVG XML, совпадение SVG с вариантом A,
баланс CSS скобок. Browser QA выполняет родитель.
