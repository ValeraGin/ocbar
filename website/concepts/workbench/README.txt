КОНЦЕПТ B / WORKBENCH

Направление: рабочая инженерная панель, сетевой patchbay, небольшая
настольная утилита. Тёплый offwhite, угольный, сигнальный оранжевый,
приглушённый голубой. Плоские большие панели, моноширинные подписи,
крупная спокойная типографика. Никаких внешних зависимостей и шрифтов.

Открыть index.html или /concepts/workbench/ на HTTP-сервере website/.
SVG иконки: icon.svg (цвет), icon-mono.svg (шаблон для menu bar).
icons.html показывает оба варианта в 16/24/32/64/128/256 на двух фонах.
Оригинальная форма — угловой штекер с кабелем, без цепи и route-fork.
icon-mono.svg использует currentColor: для AppKit template image нужен
штатный template rendering. Страница размеров встраивает SVG и показывает
светлый силуэт на тёмном фоне, тёмный на светлом.

Рабочие взаимодействия:
- два переключателя маршрутов с обновлением схемы и счётчика;
- три этапа передачи .ocbar, кнопка переходит на второй этап;
- выбор настоящего скриншота меню / настроек;
- увеличение обоих скриншотов: закрытие кнопкой, Escape и фоном;
- переключение шагов установки и копирование команд;
- если Clipboard недоступен, команды выделяются для ручного копирования;
- FAQ разворачивается штатными details;
- клавиатурная навигация табов стрелками, Home и End;
- ссылки на исходники, MIT и реальную инструкцию установки.

Схема маршрутов и передача профиля явно обозначены ДЕМО.
Установка только показывает / копирует команды, ничего не исполняет.
Скриншоты берутся из ../../dist/assets/, исходники приложения не меняются.
В них сохранена нынешняя иконка: этот концепт не редактирует скриншоты.

Тексты сверены с website/src/ru.json, README.ru.md, INSTALL.md:
одна своя VPN-сессия; другой VPN возможен при отсутствии конфликтов;
root-free у CSD и SOCKS с SystemProxy=off, обычный туннель с помощником;
допуск определяет шлюз; у ocbar нет собственных VPN-серверов;
профиль не экспортирует пароли / TOTP из хранилища, требует проверки
логина, путей и команд перед передачей.

Проверки агента: синтаксис script.js, парсинг HTML/SVG, локальные ссылки,
уникальность id и наличие якорей / ARIA-связей. Browser QA — у родителя.
