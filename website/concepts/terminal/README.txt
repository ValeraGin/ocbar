Концепт A — Route Terminal

Графитовый сайт с умеренным фосфорным зелёным, крупной типографикой,
тонкими сетками, terminal-модулями и настоящими скриншотами macOS.
Мотив бренда — развилка: один вход, два выбираемых пути.
Иконки сделаны как оригинальный SVG, без генеративного растра.

Точки входа:
  index.html — полный прототип сайта на русском
  icons.html — сравнение SVG 16/24/32/64/128/256 px на светлом/тёмном фоне
  icon.svg — иконка приложения, графитовая подложка и активная ветка
  icon-mono.svg — чёрный menu-bar glyph, прозрачный фон

Что работает:
  • якорная навигация и реальные ссылки на репозиторий/документацию
  • два переключателя маршрутов, живое описание выбора и схема
  • вкладки настоящих скриншотов, включая стрелки клавиатуры, Home/End
  • открытие скриншота в полном размере
  • копирование проверенных команд установки; выделение при отказе Clipboard API
  • раскрытие системных изменений, скачивание SVG
  • адаптивная вёрстка, reduced-motion, видимый keyboard focus

Маршруты на странице — явно помеченное демо и не меняют сеть.
Фрагмент team.ocbar — иллюстрация; кнопок фиктивного экспорта или импорта нет.
Настоящие скриншоты взяты из ../../dist/assets/; там пока прежняя иконка.
Новый знак показан отдельно в бренде, macOS-рамке, hero и завершении.
Тексты сверены с website/src/ru.json и README.ru.md:
  одна сессия ocbar, сосуществование с другим VPN при разделении сетей;
  CSD script без root, допуск определяет шлюз;
  SOCKS без root при SystemProxy = off, отдельный ocproxy;
  туннелю нужен привилегированный помощник;
  сборка из исходников Homebrew, MIT, macOS 13+ — нижняя граница,
  реально проверенная конфигурация автора macOS 26 / Apple Silicon / Keycloak.

Без новых зависимостей, внешних шрифтов, сервисов и интеграций.
Производственный website/dist и приложение не изменены.
Визуальный QA выполняет родитель в общем браузере.

Статическая проверка выполнена:
  node --check site.js — PASS
  HTMLParser: локальные файлы/якоря существуют, повторов ID нет — PASS
  ElementTree: оба SVG являются корректным XML — PASS
  Названия ключей и фрагмент профиля сверены с etc/example.ocbar.
