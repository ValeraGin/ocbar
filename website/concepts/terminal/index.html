03 / ПОД КАПОТОМ

Не чёрный ящик.
Ваш набор инструментов.

[ CSD ]

Своя обёртка HostScan.

Подключите собственный CSD wrapper. Скрипт запускается от вашего пользователя перед SSO, без root. Допуск к сети определяет шлюз.

CsdWrapper = /ваш/скрипт
[ SOCKS ]

Туннель для приложения.

Браузер, Git или отдельная команда — через локальный SOCKS. При SystemProxy = off не нужны root-помощник, системные маршруты и изменения системного DNS. Потребуется ocproxy.

Mode = proxy
[ LOGS ]

Всё видно. Всё локально.

Открывайте диагностику и журналы из меню. Смотрите маршруты, DNS, скорость и трафик. В приложении нет аналитики и отправки отчётов о сбоях.

ocbar doctor / ocbar logs
[ SSO ]

Вход без новой привычки.

SAML SSO в окне WebKit. Автозаполнение и TOTP — по желанию. Секреты хранятся в Связке ключей, KeePassXC или вашем источнике.

ocbar connect

05 / УСТАНОВКА

Начинается
с Терминала.

Homebrew собирает ocbar из исходников на вашем Mac. Нужны Command Line Tools и доступ к совместимому VPN-шлюзу.

Подробная инструкция ↗

Автор использует macOS 26 / Apple Silicon / AnyConnect + Keycloak SSO. macOS 13–25 и Intel пока не проверены.

❯ Terminal
# 1. Изучите сторонний tap, затем установите
brew tap ValeraGin/ocbar
brew trust ValeraGin/ocbar
brew install ocbar

# 2. Помощник для туннеля и приложение
sudo ocbar install
ocbar app start
Дальше — мастер настройки и первый вход.

Что установится в систему? +

Для туннеля нужны помощник и копия OpenConnect с владельцем root, фоновый агент переподключения и правило sudoers. Участники группы admin смогут запускать помощник без повторного пароля. Приложение в меню работает от вашего пользователя.

Пакет собирается локально: подписанного и нотарифицированного установщика сейчас нет. Подробнее — в модели безопасности ↗.
