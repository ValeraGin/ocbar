Install ocbar.
Make your first connection.

ocbar connects your Mac to your organization’s AnyConnect-compatible VPN gateway. You need macOS 14.4 or newer and access to that gateway.

Have a file from a teammate? Go to installation with a configured profile. It already contains the gateway, networks and DNS settings.

Install with one command

Open Terminal and paste this line:

$install_command

The command downloads the installer from GitHub. It checks Git and Swift, offers missing Apple tools and Homebrew, builds ocbar, sets up its system helper and launch at login, then opens the app.

If the Apple tools installation window appears, finish installing there: the script waits for it. The system helper needs your Mac administrator password. Run the line as your regular user. Building may take a few minutes.

Install with a configured profile

  1. Save the file from your teammate in Downloads as team.ocbar.
  2. Open Terminal and run one command:
$profile_command

This command installs the app and imports the profile before setting up the system helper. An embedded CSD script is extracted and prepared automatically. If your file has a different name or location, change its path in the command.

First connection

  1. Click ocbar in the Mac menu bar.
  2. With a configured profile, open Settings → Profiles, select it and enter your own work username. Otherwise, the wizard helps you add the gateway, networks and DNS supplied by your administrator.
  3. Choose Connect VPN and complete your organization’s sign-in with your password and second factor.
  4. To remember sign-in, choose Connect and learn the form…. You can also enter the password and code manually.
  5. Check a work resource and an ordinary public website. You can change networks or pause the connection from the menu.

Choose English, Russian or System default in Settings → General → Interface language.

The author has verified macOS 26 on Apple Silicon. A clean installation and first sign-in on another Mac have not yet been verified. Sign-in and device checks depend on your organization.

When importing in the app, the wizard offers a teammate’s file first. If an XML file contains several servers, choose the profile you need. You can change the username while keeping the configured networks and DNS.

After importing or editing CSD, the app checks its system copy before sign-in. If setup is needed, it shows sudo ocbar install and a readiness check button. Open Settings → General → Setup wizard and access check…. The wizard offers your installed profiles. Once connected, it can check a work resource: a connection to the gateway alone does not confirm access to services.

Tell us how your gateway worked: gateway type, sign-in method and result are enough. Do not include corporate addresses or sign-in details.

If the connection fails

ocbar doctor
ocbar status

The app also has a diagnostics and logs window. Start with any failed checks; confirm your gateway, group and authentication requirements with your administrator. Detailed troubleshooting (Russian) covers common failures. Before opening a public issue, remove gateway details, account names, cookies and tokens from any logs you share.

Update

brew upgrade ocbar
ocbar app stop
ocbar app start
ocbar doctor

If the release notes or diagnostics report an outdated helper, run sudo ocbar install again. Updates are not installed automatically.

Share a configured profile with a teammate

One .ocbar file brings together the gateway, networks, DNS zones and SSO form rules. New teammates can start with settings you have already checked.

ocbar export main team.ocbar

Here, main is the name of your configured profile. Before sharing, open the file: replace your personal User value, review KeePassXC and CSD wrapper paths, and check any custom commands. Export does not retrieve passwords or TOTP secrets from your credential store; you must review the contents of your own commands and rules. Share work settings within your team.

If CSD is required, open the profile editor’s advanced settings and choose Embed CSD script… before exporting. Export preserves the script inside the file.

Send your teammate team.ocbar and the link to installation with a configured profile. One command installs the app; they then enter their own username and sign in as themselves.

Remove the app and system helper

Keep this order: ocbar must still be installed to remove its system components.

sudo ocbar uninstall
brew uninstall ocbar

The first command disconnects ocbar, removes its routes and DNS settings, stops its agents, and removes the helper and its sudoers rule. The second removes the Homebrew package.

Profiles, local logs and state, saved WebKit sign-in data and Keychain credentials remain. These commands are not a full personal-data wipe. Review the full cleanup instructions (Russian) before deleting remaining data. KeePassXC entries are managed separately.
